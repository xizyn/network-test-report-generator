# 文件支持矩阵

| 文件类型 | V1 状态 | 处理方式 |
|---|---|---|
| DOCX | 支持 | 扫描段落/表格/页眉页脚批注；复制模板后局部替换。 |
| XLSX | 支持 | 读取工作表常见“字段—值”行，记录 Sheet/Cell 来源。 |
| XLS | 基础支持 | 通过 ExcelDataReader 读取；损坏/加密时标记人工处理。 |
| CSV/TXT | 支持 | UTF-8 CSV 或制表符文本的字段—值提取。 |
| JPG/PNG/BMP/TIFF | 支持归档 | 识别真实图片类型，供人工关联；图片字段自动嵌入为后续增强项。 |
| PDF | 支持归档 | 识别并作为附件记录；扫描 PDF 与 OCR 不自动提取，人工录入来源。 |
| DOC/WPS/ET | 降级 | 识别/归档；请在 WPS 中另存为 DOCX/XLSX 后导入。 |
| DWG/DXF | 降级 | 识别与归档；转 PDF/PNG 后作为图纸资料处理。 |
| FEL | 降级 | 归档并引导使用 Fluke Energy Analyze Plus 导出 CSV/XLSX。 |
| ZIP/OLE/未知 | 人工确认 | 显示真实检测结果，不猜测内容。 |

加密、密码保护或损坏文件必须由工程师处理后重新导入；系统会继续扫描其余文件。
