# WPS 报告模板制作指南

1. 在 WPS Writer 中打开公司空白模板的副本。
2. 在需要替换的位置输入一个可见占位文本，例如 `XXXXXXXX`。占位文本可以跨多个字体 Run，但不要跨段落、跨单元格或跨页眉/正文结构。
3. 选中完整占位文本，使用“审阅 → 新建批注”，批注内容填写标准字段名，例如 `项目名称`、`客户名称`、`装机容量`、`逆变器型号`、`测试日期`。
4. 同一个字段需要多处显示时，在每处添加同名批注；系统会视为“同字段多目标”，不是冲突。
5. 保存为 `.docx`。请不要保存为 `.doc` 或 `.wps` 后直接导入。
6. 在系统中扫描模板并检查“模板原内容”。若字段范围为空、跨越不同结构或批注为空，将显示为待人工处理。

字段名优先使用统一中文名。当前预置别名包括：`委托单位/委托方/建设单位 → 客户名称`，`工程名称/电站名称 → 项目名称`，`总容量/容量 → 装机容量`，`试验日期/检测日期 → 测试日期`。别名匹配必须人工勾选确认后才能用于正式报告。

正式签章和数字签名应在报告内容终审后再进行；修改已签章 DOCX 可能导致签名失效。
